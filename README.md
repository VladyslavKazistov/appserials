# Премьеры: веб-приложение для телефона

Показывает новые фильмы и сериалы с оценкой TMDB не ниже вашего порога, ближайшие премьеры, поиск и избранное с напоминаниями.

## Как установить на телефон
1. Разместите эту папку на любом бесплатном хостинге с HTTPS (GitHub Pages, Netlify, Cloudflare Pages).
2. Откройте адрес на телефоне:
   - iPhone: Safari → «Поделиться» → «На экран „Домой“»;
   - Android: Chrome → меню → «Установить приложение».
3. При первом запуске откройте «Настройки» и вставьте ключ TMDB (бесплатно: themoviedb.org → Settings → API). Ключ хранится только на телефоне.

## Ограничения
- Уведомления приходят, когда приложение открыто или недавно открывалось. Для пушей при полностью закрытом приложении нужен небольшой сервер, это можно добавить позже.
- Если TMDB не открывается у вашего провайдера, может понадобиться VPN.
